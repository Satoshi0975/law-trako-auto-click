# SSDLC Auto Click

> SSDLC 一直點「符合」很煩？ 這邊幫你一鍵符合！

## 安裝方式

### 步驟一：下載檔案

將整個 `my-extension` 資料夾存放到你的電腦中任意路徑

### 步驟二：開啟 Chrome 擴充功能頁面

在網址列輸入：

```
chrome://extensions
```

### 步驟三：開啟開發人員模式

點擊右上角的「**開發人員模式**」開關，將其切換為開啟狀態。

### 步驟四：載入擴充功能

點擊左上角的「**載入未封裝項目**」按鈕，選擇 `my-extension` 資料夾。

### 步驟五：確認安裝成功

安裝完成後，Chrome 右上角工具列會出現擴充功能圖示，代表安裝成功。

---

## 使用方式

1. 前往SSDLC頁面
2. 點擊右上角工具列的擴充功能圖示
3. 在彈出視窗中點擊「**點擊所有「符合」**」按鈕
4. 所有的SSDLC確認項目都會勾選**「符合」**
5. 請記得將不適用的項目自己勾回來

---

## 注意事項

- 本擴充功能僅在本機開發模式運行，未上架至 Chrome Web Store
- 請勿刪除 `my-extension` 資料夾，否則擴充功能將失效
- 若瀏覽器更新後擴充功能消失，重新執行步驟三至五即可
